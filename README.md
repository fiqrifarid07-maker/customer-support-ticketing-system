# IQ-TECH HELPDESK – Switch Network Support Portal

An interactive HTML prototype for a network switch & infrastructure support helpdesk system.

## Features
- Login & Customer Registration
- Customer Dashboard with ticket statistics
- Create Ticket form (with switch-specific fields)
- My Tickets list & Ticket Conversation view
- Support Staff Dashboard & Ticket Management
- Support Ticket Details with switch asset sidebar

## Pages Included
1. Login Page
2. Customer Registration Page
3. Customer Dashboard
4. Create Ticket Page
5. My Tickets Page
6. Ticket Details (Customer)
7. Support Dashboard
8. Ticket Management Page
9. Support Ticket Details Page

## How to Use
Open `prototip_antaramuka_interaktif.html` in any modern browser.
Use the **"Jump to Screen"** dropdown at the top to navigate between all 9 pages.

## Technologies
- HTML5
- Tailwind CSS (CDN)
- Font Awesome 6.4 (CDN)
- Vanilla JavaScript (view switching)
